# 🎬 CineMate — Твой личный кинотрекер

**CineMate** — это полноценное Full-stack веб-приложение для поиска фильмов и ведения личной коллекции. Проект создан с нуля для демонстрации навыков разработки.

🔗 **[Живая демо-версия](https://cinemate-83ib.onrender.com)** 
*(Внимание: сайт хостится на бесплатном тарифе Render, поэтому первый заход может занять до 50 секунд для "пробуждения" сервера).*

---

## 🚀 Функционал

- 🔐 **Аутентификация:** Регистрация и вход с использованием JWT-токенов (хранятся в HttpOnly Cookie).
- 🔍 **Интеграция с внешним API:** Поиск фильмов в реальном времени через TMDB API (с локализацией на русский язык).
- 📝 **Личный кабинет:** Добавление фильмов в избранное, выставление оценок от 1 до 10.
- 📊 **Статистика:** Отслеживание статусов фильмов (хочу посмотреть / просмотрено).
- 🎨 **Адаптивный интерфейс:** Сверстан с помощью Bootstrap 5 без использования сложных JS-фреймворков (используется Vanilla JS для AJAX-запросов).

---

## 🛠 Стек технологий

**Backend:**
* Python 3
* FastAPI (веб-фреймворк)
* SQLAlchemy 2.0 (ORM)
* PostgreSQL (база данных)
* Pydantic (валидация данных)
* JWT + bcrypt (безопасность и авторизация)
* httpx (асинхронные запросы к TMDB API)

**Frontend:**
* Jinja2 (серверный рендеринг)
* Bootstrap 5 (стилизация)
* Vanilla JavaScript (интерактивность)

**Инфраструктура:**
* Git / GitHub
* Render (хостинг приложения и базы данных)
